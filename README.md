# Zombie Wave Shooter 3D

A simple 3D zombie shooter game developed using C++ and OpenGL.

## Features
- 3D zombie enemies
- Shooting mechanics
- Wave and score system
- Health and ammo system
- Graveyard environment
- Basic collision detection

## Technologies Used
- C++
- OpenGL
- GLUT
